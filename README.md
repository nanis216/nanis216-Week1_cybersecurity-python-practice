Cybersecurity Python Practice

##Repository Purpose
This repository contains Python practice exercises completed as part of the **freeCodeCamp Scientific Computing with Python certification** for Week 1.

The exercises demonstrate fundamental Python concepts required for cybersecurity scripting and automation.

##Files Included
**Variables.py**
Demonstrates variables, data types and output statements.

**conditions.py**
Demonstrates conditional statements and decision making using if/else statements.

**functions.py**
Demonstrates the creation and execution of Python functions.

**lists.py**
Demonstrates the use of lists and loops.

**dictionary.py**
Demonstrates the use of dictionaries and key-value pairs.

## Skills Practiced

During this activity, the following Python concepts were practiced:

- Variables
- Data Types
- Strings
- Lists
- Dictionaries
- Functions
- Conditional Statements
- Loops
